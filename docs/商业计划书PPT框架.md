> 用途：5 分钟路演商业计划书（BP），配合 2 分钟 Demo 视频
> 页数：**12 页**（老师要求最多 15 页，留 3 页 buffer）
> 总时长：≈5 分 20 秒（演讲时略快可压到 5 分钟内）
> 设计依据：项目制作方案.md 第 3 / 12 / 13 / 14 节

## 一、页数分配逻辑（为什么是 12 页）

5 分钟 ≈ 300 秒，按每页 20–40 秒的节奏，叙事顺序：**大环境 → 痛点 → 市场 → 产品 → 技术 → 效果 → 商业**。

- 封面：1 页（15s）
- 大环境（为什么现在做）：1 页（20s，监管 + 技术交汇）
- 用户痛点：1 页（30s，必须讲透"为什么需要"）
- 市场与竞争（目标用户）：1 页（40s，★重点，竞品矩阵）
- 产品 + 技术：4 页（产品方案 / 核心流程 / Agent 架构 / 核心创新）
- 测试与效果：1 页（30s，用真实数据建立可信度）
- 商业 + 触达：2 页（B2C/B2B + 首批用户来源）
- 发展请求：1 页（发展计划与请求）

共 12 页。

> 备注：团队分工不单独占页，但仍是合作证明——建议放在封面小字或口头介绍，并在 README / 仓库里写明分工（老师看团队合作证明时查得到）。

### P3 · 用户痛点（30s）★ 重点
**核心信息**：金融文件长、专业、关键条件散落几十页，普通人找不到、看不懂。
**文字（3 个 bullet）**
- 一份理财产品说明书往往 20–50 页，保本/收益/锁定期/费用分散在不同章节
- 宣传海报几秒讲收益，风险与退出条件却被弱化
- SEC / OECD 研究：个人投资者更想要"摘要式、分层式披露"（引方案 3.1 表 E1–E4）
**视觉**
- 📸 左图：脱敏后的真实说明书一页（`sample_data/模拟理财产品说明书.pdf` 导出图片）
- 🔷 右图：自制"碎片化"示意图——把说明书里 4 个关键条件（保本 / 业绩比较基准 / 资金锁定期 / 费率）用黄色高亮框标出，分散在页面四角，旁边一个大问号"普通人在哪找？"
- ⚠️ 红线：不虚构"我妈看不懂"这类访谈原话，只引权威研究

## 四、⚠️ 答辩高风险提醒（老师可能会追问）

1. **不虚构市场数据**：方案 3.2 的 H1–H5 是**未验证假设**（用户愿不愿用、愿不愿付费、机构愿不愿采购等）。PPT 中**不得写成已验证事实**，禁止出现"调研证明 X% 用户愿意使用并付费"这类话。
2. **竞品措辞**：见 P4 红线，必须承认有类似产品，强调"组合到细分场景"的差异。
3. **边界声明**：产品**不构成投资建议**，仅做信息整理与风险解释，避免触碰金融持牌红线。
