## 1. 项目定位和当前版本

明白金是一款金融产品购买前信息核验 Agent：它将宣传材料与正式说明书逐项对照，把收益、本金、期限、费用和风险翻译成普通用户能理解的说明，并为每个结论提供可追溯证据。

当前版本为可运行的课程 MVP，首要用户是普通金融消费者。金融机构营销材料初审是未来 B2B 延伸设想，不属于当前已验证交付。

## 2. 技术与产品选择

- 前端与应用框架：Streamlit；
- PDF 文字解析：`pdfplumber`，保留页面边界；
- 确定性分析：Python 规则引擎；
- 语义增强：可选的分析 Agent 与核验 Agent；
- 防幻觉：独立核验加程序逐字引用门控；
- 模型接入：用户自行提供 API 配置；
- 导出：Markdown、JSON、Word 和 PDF。

选择混合模式的原因是：无 API 时仍可稳定演示，复杂语义可以由模型补充，但模型新增内容不能绕过证据核验。

## 8. 已知限制

- 仅支持有可复制文字的 PDF，不支持纯扫描件 OCR；
- 单次分析一个产品；
- 规则覆盖有限，模型输出也可能不稳定；
- 模型文档输入上限为 45,000 字符；发生截断时页面和报告会提示，截断后的 Agent 结果不能视为全文审查；
- 引用存在不等于解释必然正确；
- 主要测试材料为模拟案例，不能代表全部真实金融产品；
- 不处理真实客户敏感资料；
- 不构成投资建议、收益承诺、法律意见、正式合规审查或适当性评估。

## 9. 市场对比

市场上已有通用大模型、PDF 问答、合同风险识别、金融文件分析和费用分析工具。本项目不声称“没有竞品”。当前差异化设想是把宣传材料—正式说明书对照、通俗解释和页码证据组合到中国金融消费者购买前场景。

竞品事实、功能与最新状态应在制作 PPT 前重新核验并保留来源；未核验内容不能写成确定结论。
