# 教学模拟测试材料

本目录中的产品、机构、数据、条款和宣传文案均为课程教学模拟，不对应任何真实金融机构或真实金融产品，不构成投资建议。

## 文件说明

- `模拟理财产品说明书.pdf`：供系统上传和解析的正式测试文件。
- `模拟理财产品说明书_源文本.md`：PDF 的可编辑源内容。
- `模拟宣传文案.md`：故意突出业绩比较基准并遗漏重要风险的测试文案。
- `人工标准答案.json`：团队人工制作的结构化标准答案，用于验证模型输出。
- `build_sample_pdf.py`：生成模拟说明书 PDF 的脚本。

## 演示目标

系统应当从材料中识别：

1. 产品不保证本金和收益；
2. 3.20% 是业绩比较基准，不是承诺收益；
3. 产品期限为 180 天；
4. 存续期内原则上不允许投资者提前赎回；
5. 产品收取固定管理费、托管费和销售服务费；
6. 产品主要面临市场、信用、流动性和信息传递等风险；
7. 宣传文案遗漏了非保本、提前赎回限制和费用信息；
8. “到期稳稳拿”等表达容易使消费者产生确定收益预期。

## 安全边界

- 不使用真实客户信息。
- 不连接真实账户。
- 不用于真实购买、销售或适当性判断。
- Demo 中应始终保留“教学模拟”标识。
